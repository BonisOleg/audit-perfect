## 1. Призначення сайту

Корпоративний сайт аудиторської компанії **Аудит-Перфект** (ПП «АФ «Аудит-Перфект»»). Мова — **лише українська**.

Послуги v1.1 (Правки 1):

1. аудиторські
2. бухгалтерські
3. трансфертне ціноутворення
4. контрольовані іноземні компанії (КІК)
5. військовий облік (у т.ч. статус критично важливого підприємства)
6. юридичні
7. кадровий супровід

CMS дозволяє додати ще напрям без зміни верхнього меню.

- Метрики: 19 / 500 / 25 / 50
- Переваги (3): команда · статус критичності · супровід перевірок
- Команда: 8 осіб + фото
- Сертифікати: Реєстр №3975 + лінк; свідоцтво про держреєстрацію; диплом ACCA DipIFR; адвокатське — пізніше
